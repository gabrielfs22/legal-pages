BRADUC Studio

An independent animation studio creating short anime-style fantasy stories.

BRADUC Studio writes, illustrates and animates original short videos set in fantasy worlds: adventurers, ruins, magic and quiet dramatic moments told in under a minute. Each episode goes through a full production pipeline (story, storyboard, keyframes, animation, narration and soundtrack) and is published as a vertical short video.

Original stories

Every short is written in-house, from premise to final scene.

Anime-style art

Directed keyframes and animation with a consistent visual style.

Short format

Vertical videos made for YouTube Shorts, TikTok and Instagram Reels.

BRADUC Studio Publisher

BRADUC Studio Publisher is the studio's publishing tool. It uploads finished videos, with title, description and tags, to the studio's own accounts using each platform's official API (YouTube Data API, Meta Graph API and TikTok Content Posting API). Access to each account is granted through the platform's official OAuth flow and can be revoked at any time.

The tool does not collect data from other users and does not post on behalf of third parties. Details are in the Privacy Policy and the Terms of Service.
