Privacy Policy

Last updated: October 9, 2026.

This policy covers "BRADUC Studio Publisher", the publishing tool operated by BRADUC Studio to publish videos produced by the studio on the studio's own social media accounts (YouTube, Facebook, Instagram, TikTok).

Data we process

  • Access tokens (OAuth) for the studio's own accounts, required to authorize publishing through each platform's API. These tokens are stored locally in a private file and are never shared with third parties.
  • Metadata of the published video (title, description, tags), which is content created by the studio for public release.

Data we do not collect

The app does not collect, store or process personal data of other platform users (viewers, followers, commenters). No third-party data is collected in any way.

Data sharing

No data is shared with third parties. The only network calls the app makes are to the platforms' official APIs (YouTube Data API, Meta Graph API, TikTok Content Posting API), using the studio's own credentials.

Retention and deletion

Access tokens can be revoked at any time in each platform's settings (e.g. TikTok → Settings → Security and permissions → Apps and services). Revoking access immediately stops the app from publishing to that account; locally stored tokens can be deleted on request.

Contact

Questions about this policy: braduc.studio@gmail.com.

Política de Privacidade

Última atualização: 9 de outubro de 2026.

Esta política cobre o "BRADUC Studio Publisher", a ferramenta de publicação operada pela BRADUC Studio para publicar vídeos produzidos pelo estúdio nas contas de mídia social do próprio estúdio (YouTube, Facebook, Instagram, TikTok).

Quais dados são processados

  • Tokens de acesso (OAuth) das contas do próprio estúdio, necessários para autorizar a publicação via API. Esses tokens são armazenados localmente, em arquivo privado, e nunca compartilhados com terceiros.
  • Metadados do vídeo publicado (título, descrição, tags), conteúdo criado pelo estúdio para publicação pública.

O que não é coletado

O aplicativo não coleta, armazena nem processa dados pessoais de outros usuários das plataformas (espectadores, seguidores, comentaristas). Não há coleta de dados de terceiros de nenhuma forma.

Compartilhamento de dados

Nenhum dado é compartilhado com terceiros. As únicas chamadas de rede realizadas são para as APIs oficiais das plataformas (YouTube Data API, Meta Graph API, TikTok Content Posting API), usando as credenciais do próprio estúdio.

Retenção e exclusão

Os tokens de acesso podem ser revogados a qualquer momento nas configurações de cada plataforma (ex.: TikTok → Configurações → Segurança e permissões → Apps e serviços). A revogação impede imediatamente novas publicações naquela conta; os tokens armazenados localmente podem ser apagados mediante pedido.

Contato

Dúvidas sobre esta política: braduc.studio@gmail.com.
