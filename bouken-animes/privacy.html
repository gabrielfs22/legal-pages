Política de Privacidade — Bouken Animes

Última atualização: 30 de setembro de 2026.

Este aplicativo ("Bouken Animes Publisher") é uma ferramenta pessoal de automação, usada exclusivamente pelo próprio desenvolvedor para publicar vídeos nas suas próprias contas de mídia social (YouTube, Facebook, Instagram, TikTok).

Quais dados são processados

  • Tokens de acesso (OAuth) das próprias contas do desenvolvedor, necessários para autorizar a publicação via API. Esses tokens são armazenados localmente, em arquivo privado, e nunca compartilhados com terceiros.
  • Metadados do vídeo publicado (título, descrição, tags) — conteúdo criado pelo próprio desenvolvedor para publicação pública.

O que não é coletado

O aplicativo não coleta, armazena nem processa dados pessoais de outros usuários das plataformas (espectadores, seguidores, comentaristas). Não há coleta de dados de terceiros de nenhuma forma.

Compartilhamento de dados

Nenhum dado é compartilhado com terceiros. As únicas chamadas de rede realizadas são para as APIs oficiais das próprias plataformas (YouTube Data API, Meta Graph API, TikTok Content Posting API), usando as credenciais do próprio desenvolvedor.

Retenção e exclusão

Tokens de acesso podem ser revogados a qualquer momento pelo desenvolvedor diretamente nas configurações de cada plataforma (ex.: TikTok → Configurações → Apps conectados).
